# Реализация функционала построения маршрутов и управления заказами

## Завершенные задачи

### 1. Фронтенд: выбор точки назначения и построение маршрута
**Файл:** `frontend/src/pages/MapPage.tsx`

#### Реализованный функционал:
- **Новые состояния:**
  - `destLat`, `destLng` - координаты точки назначения
  - `distanceKm` - расстояние маршрута в километрах
  - `rideCost` - рассчитанная стоимость поездки
  - `rideCostLoading`, `rideCostError` - состояние расчета стоимости
  - `activeOrder` - активный заказ пользователя
  - `orderLoading`, `orderError` - состояние операций с заказами

- **Обработка кликов по карте:**
  - При клике по карте устанавливается красный маркер точки назначения
  - Удаляется предыдущий маркер и маршрут при новом клике
  - Автоматическое построение маршрута при выборе автомобиля и точки назначения

- **Построение маршрута:**
  - Интеграция с библиотекой `leaflet-routing-machine`
  - Автоматический расчет расстояния после построения маршрута
  - Визуализация маршрута синей линией на карте

- **Расчет стоимости:**
  - Автоматический расчет стоимости при изменении расстояния
  - Интеграция с API `POST /api/ride-cost/calculate`
  - Отображение ошибок расчета стоимости

- **Управление заказами:**
  - Создание заказа с рассчитанной стоимостью
  - Завершение активного заказа
  - Обновление статуса автомобилей в реальном времени
  - Обработка ошибок авторизации и валидации

#### Пользовательский интерфейс:
- **Панель маршрута:** Отображение координат точки назначения, расстояния и стоимости
- **Кнопки действий:** 
  - "Создать заказ" - при наличии рассчитанной стоимости
  - "Завершить поездку" - для активного заказа
  - "Очистить маршрут" - удаление маршрута и точки назначения
- **Инструкция:** Пошаговое руководство по построению маршрута
- **Легенда:** Цветовые обозначения статусов автомобилей

## Интеграция с бэкендом

### Связь с существующими API:
1. **Аутентификация:** Используется существующая система JWT токенов через `authApi.getAccessToken()`
2. **Проверка статуса пользователя:** Автоматическая проверка `user.isBlocked()` и `user.isVerified()` на бэкенде
3. **Расчет стоимости:** Интеграция с `RideCostController` и `RideCostService`
4. **Управление заказами:** Интеграция с `OrderController` и `OrderService`

### Безопасность:
- Все запросы требуют авторизации через JWT токен
- Проверка статуса пользователя (заблокирован/верифицирован) на бэкенде
- Валидация входных данных на клиенте и сервере

## Тестирование функционала

### Сценарии использования:
1. **Построение маршрута:**
   - Выберите автомобиль из списка
   - Кликните на карте для установки точки назначения
   - Наблюдайте построение маршрута и расчет расстояния

2. **Создание заказа:**
   - Постройте маршрут и дождитесь расчета стоимости
   - Нажмите "Создать заказ" (требуется авторизация и верификация)
   - Автомобиль перейдет в статус "IN_USE"

3. **Завершение заказа:**
   - При активном заказе нажмите "Завершить поездку"
   - Заказ будет завершен, автомобиль вернется в статус "AVAILABLE"
   - Маршрут будет очищен

### Обработка ошибок:
- **Нет авторизации:** Сообщение "Требуется авторизация"
- **Пользователь заблокирован:** Сообщение "Доступ запрещен"
- **Автомобиль недоступен:** Сообщение "Автомобиль не доступен"
- **Заказ не найден:** Сообщение "Заказ не найден"
- **Заказ уже завершен:** Сообщение "Заказ уже завершен"
