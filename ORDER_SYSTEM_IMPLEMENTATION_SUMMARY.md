# Реализация системы управления заказами

## Выполненные задачи

### 1. Удаление поля `disabled` из модели User
- Убрано поле `is_disabled` из `User.java`
- Обновлен `RideCostServiceImpl` - скидка всегда 0%
- Обновлен `DataInitializer` - убрана установка поля `disabled`

### 2. Обновление OrderStatus enum
- Добавлены новые статусы: `STARTED`, `COMPLETED`, `CANCELLED`
- Сохранены существующие: `PAID`, `UNPAID`, `IN_PROCESS`

### 3. Создание DTO классов
- **OrderDto.java** - DTO для заказа
- **CreateOrderRequest.java** - запрос на создание заказа (`carId`, `price`)
- **EndOrderRequest.java** - запрос на завершение заказа (`distanceKm`, `spendFuel`)

### 4. Создание исключений
- **CarNotAvailableException.java** - автомобиль не доступен (409)
- **OrderNotFoundException.java** - заказ не найден (404)
- **OrderAlreadyCompletedException.java** - заказ уже завершен (422)

### 5. Реализация OrderService
- **OrderService.java** - интерфейс сервиса
- **OrderServiceImpl.java** - реализация с методами:
  - `createOrder()` - создает заказ, проверяет доступность автомобиля
  - `endOrder()` - завершает заказ, проверяет существование и статус

### 6. Создание репозитория и маппера
- **OrderRepository.java** - JPA репозиторий для Order
- **OrderMapper.java** - маппер между Order и OrderDto

### 7. Реализация OrderController
- **OrderController.java** - контроллер с эндпоинтами:
  - `POST /api/orders/create` - создание заказа
  - `PUT /api/orders/{orderId}/end` - завершение заказа
- Проверка авторизации через `AdminAccessService`
- Проверка статуса пользователя (`blocked`, `verified`)

### 8. Обновление GlobalExceptionHandler
- Добавлена обработка новых исключений:
  - `CarNotAvailableException` → 409 Conflict
  - `OrderNotFoundException` → 404 Not Found
  - `OrderAlreadyCompletedException` → 422 Unprocessable Entity

## Архитектура решения

### Создание заказа
```
OrderController.createOrder()
    ↓
AdminAccessService.requireUser() (проверка авторизации)
    ↓
OrderService.createOrder()
    ↓
1. Проверка доступности автомобиля (CarStatus.AVAILABLE)
2. Создание Order со статусом STARTED
3. Обновление CarStatus на IN_USE
4. Сохранение заказа
    ↓
Возврат OrderDto
```

### Завершение заказа
```
OrderController.endOrder()
    ↓
AdminAccessService.requireUser() (проверка авторизации)
    ↓
OrderService.endOrder()
    ↓
1. Проверка существования заказа
2. Проверка статуса заказа (не COMPLETED)
3. Установка endTime = текущее время
4. Обновление статуса на COMPLETED
5. Запись distance и spendFuel
6. Обновление CarStatus на AVAILABLE
    ↓
Возврат OrderDto
```

## Логика работы

### Создание заказа
1. **Проверка пользователя:**
   - Авторизован ли
   - Верифицирован ли
   - Не заблокирован ли

2. **Проверка автомобиля:**
   - Существует ли автомобиль с указанным `carId`
   - Находится ли в статусе `AVAILABLE`

3. **Создание заказа:**
   - `startTime` = текущее время
   - `status` = `STARTED`
   - `price` = переданная стоимость
   - `discount` = 0.0
   - `ratingEdits` = 0.0

4. **Обновление автомобиля:**
   - `CarStatus` = `IN_USE`

### Завершение заказа
1. **Проверка пользователя:** (аналогично созданию)
2. **Проверка заказа:**
   - Существует ли заказ с указанным `orderId`
   - Не завершен ли уже (`status` != `COMPLETED`, `endTime` == null)

3. **Завершение заказа:**
   - `endTime` = текущее время
   - `status` = `COMPLETED`
   - `distance` = переданное расстояние
   - `spendFuel` = переданное топливо (опционально)

4. **Обновление автомобиля:**
   - `CarStatus` = `AVAILABLE`

## Коды ошибок HTTP

| Ситуация | Код HTTP | Исключение | Сообщение |
|----------|----------|------------|-----------|
| Автомобиль не доступен | 409 | CarNotAvailableException | "Автомобиль не доступен" |
| Заказ не найден | 404 | OrderNotFoundException | "Заказ не найден" |
| Заказ уже завершен | 422 | OrderAlreadyCompletedException | "Заказ уже завершен" |
| Автомобиль не найден | 404 | CarNotFoundException | "Автомобиль не найден" |
| Нет авторизации | 401/403 | AccessDeniedException | "Недостаточно прав" |
| Пользователь заблокирован | 403 | - | 403 Forbidden |
| Пользователь не верифицирован | 403 | - | 403 Forbidden |
