Test Logging for Order Creation

Instructions:

This test simulates the logging that happens when creating or ending an order in the carsharing application.

Click the buttons below to see what data would be logged to the browser console when:

  1. Creating an order
  2. Ending an order with route data
  3. Ending a ride without an order

Note: Open browser developer tools (F12) to see the actual console output.

Test 1: Create Order Logging

Simulates logging when creating a new order.

Test 2: End Order Logging

Simulates logging when ending an order with route data.

Test 3: End Ride Without Order Logging

Simulates logging when ending a ride without an active order.
