# API расчета стоимости поездки

## Эндпоинт

`POST /api/ride-cost/calculate`

## Описание
Рассчитывает стоимость поездки на основе выбранного автомобиля и расстояния.

## Требования к авторизации
- Пользователь должен быть авторизован (передать токен в заголовке `Authorization: Bearer <token>`)
- Пользователь должен быть верифицирован (`verified: true`)
- Пользователь не должен быть заблокирован (`blocked: false`)

## Запрос

### Заголовки
```
Authorization: Bearer <jwt-token>
Content-Type: application/json
```

### Тело запроса (JSON)
```json
{
  "carId": 1,
  "distanceKm": 10.5
}
```

### Поля запроса
| Поле | Тип | Обязательно | Описание |
|------|-----|-------------|----------|
| carId | Long | Да | ID автомобиля |
| distanceKm | double | Да | Расстояние в километрах |

## Ответ

### Успешный ответ (200 OK)
```json
{
  "totalCost": 63.0,
  "baseRate": 4.0,
  "coefficient": 1.5,
  "discountPercent": 0.0,
  "distanceKm": 10.5
}
```

### Поля ответа
| Поле | Тип | Описание |
|------|-----|----------|
| totalCost | double | Итоговая стоимость поездки |
| baseRate | double | Базовая ставка (4.0) |
| coefficient | double | Коэффициент автомобиля (из CarModel) |
| discountPercent | double | Процент скидки (3% для пользователей с ограниченными возможностями) |
| distanceKm | double | Расстояние в километрах |

## Ошибки

### 401 Unauthorized
```json
{
  "message": "Недостаточно прав"
}
```
Причины:
- Отсутствует заголовок Authorization
- Неверный формат токена
- Токен не начинается с "Bearer "

### 403 Forbidden
```json
{
  "message": "Недостаточно прав"
}
```
Причины:
- Пользователь заблокирован (`blocked: true`)
- Пользователь не верифицирован (`verified: false`)

### 404 Not Found
```json
{
  "message": "Автомобиль не найден"
}
```
Причины:
- Автомобиль с указанным `carId` не существует

### 500 Internal Server Error
```json
{
  "message": "Внутренняя ошибка сервера"
}
```
Другие внутренние ошибки сервера.

## Формула расчета
```
totalCost = distanceKm * baseRate * coefficient * (1 - discountPercent/100)
```

Где:
- `baseRate` = 4.0 (фиксированная ставка)
- `coefficient` = коэффициент автомобиля из `CarModel.coefficient`
- `discountPercent` = 3.0 если `user.disabled = true`, иначе 0.0

## Примеры

### Пример 1: Обычный пользователь
**Запрос:**
```json
{
  "carId": 1,
  "distanceKm": 15.0
}
```
**Предположим:**
- Автомобиль с ID 1 имеет коэффициент 1.2
- Пользователь не имеет ограничений по здоровью (`disabled: false`)

**Расчет:**
```
totalCost = 15.0 * 4.0 * 1.2 * (1 - 0/100) = 72.0
```

**Ответ:**
```json
{
  "totalCost": 72.0,
  "baseRate": 4.0,
  "coefficient": 1.2,
  "discountPercent": 0.0,
  "distanceKm": 15.0
}
```

### Пример 2: Пользователь с ограниченными возможностями
**Запрос:**
```json
{
  "carId": 2,
  "distanceKm": 20.0
}
```
**Предположим:**
- Автомобиль с ID 2 имеет коэффициент 1.5
- Пользователь имеет ограничения по здоровью (`disabled: true`)

**Расчет:**
```
totalCost = 20.0 * 4.0 * 1.5 * (1 - 3/100) = 20.0 * 4.0 * 1.5 * 0.97 = 116.4
```

**Ответ:**
```json
{
  "totalCost": 116.4,
  "baseRate": 4.0,
  "coefficient": 1.5,
  "discountPercent": 3.0,
  "distanceKm": 20.0
}
```

## Тестирование

### Валидные данные
1. Авторизованный, верифицированный, не заблокированный пользователь
2. Существующий `carId`
3. Положительное значение `distanceKm`

### Невалидные данные
1. Отсутствие авторизации → 401/403
2. Заблокированный пользователь → 403
3. Неверифицированный пользователь → 403
4. Несуществующий `carId` → 404
5. Отрицательное или нулевое `distanceKm` → 400 (валидация на фронтенде)

## Интеграция с фронтендом
Для использования этого API на фронтенде необходимо:
1. Получить JWT токен при авторизации
2. Сохранить его в localStorage или cookies
3. Передавать в заголовке `Authorization` для всех запросов к этому эндпоинту
4. Обрабатывать ошибки 401/403 для перенаправления на страницу авторизации
