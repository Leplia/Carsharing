# Реализация системы расчета стоимости поездки

## Выполненные задачи

### 1. Создание DTO классов
- **RideCostRequest.java** - запрос с полями `carId` и `distanceKm`
- **RideCostResponse.java** - ответ с полями `totalCost`, `baseRate`, `coefficient`, `discountPercent`, `distanceKm`

### 2. Реализация сервиса
- **RideCostService.java** - интерфейс сервиса
- **RideCostServiceImpl.java** - реализация с логикой расчета:
  - Базовая ставка: 4.0
  - Коэффициент берется из `CarModel.coefficient`
  - Скидка 3% для пользователей с `disabled = true`
  - Формула: `distanceKm * baseRate * coefficient * (1 - discountPercent/100)`

### 3. Создание контроллера
- **RideCostController.java** - эндпоинт `POST /api/ride-cost/calculate`
- Проверка авторизации через `AdminAccessService`
- Проверка статуса пользователя (`blocked`, `verified`)
- Обработка ошибок через глобальный обработчик исключений

### 4. Обработка исключений
- **CarNotFoundException.java** - кастомное исключение для автомобиля не найден
- Обновлен **GlobalExceptionHandler.java** для обработки `CarNotFoundException`

### 5. Обновление модели User
- Добавлено поле `disabled` в модель `User.java`
- Обновлен **DataInitializer.java** для установки поля при создании пользователя

### 6. Фронтенд компоненты
- **ride.api.ts** - API клиент для расчета стоимости
- **RideCostCalculator.tsx** - React компонент калькулятора
- **RideCostCalculator.css** - стили для компонента

### 7. Документация
- **API_RIDE_COST.md** - полная документация API
- **RIDE_COST_IMPLEMENTATION_SUMMARY.md** - этот отчет

## Архитектура решения

### Бэкенд
```
RideCostController
    ↓
AdminAccessService (проверка авторизации)
    ↓
RideCostService
    ↓
RideCostServiceImpl
    ↓
CarsRepository (получение автомобиля)
    ↓
CarNotFoundException (если автомобиль не найден)
```

### Фронтенд
```
RideCostCalculator (React компонент)
    ↓
calculateRideCost (API клиент)
    ↓
POST /api/ride-cost/calculate
    ↓
Обработка ответа/ошибок
```

## Формула расчета
```
totalCost = distanceKm * baseRate * coefficient * (1 - discountPercent/100)
```

Где:
- `baseRate` = 4.0 (фиксированная ставка за км)
- `coefficient` = коэффициент автомобиля (1.0-3.0)
- `discountPercent` = 3.0 если `user.disabled = true`, иначе 0.0

## Примеры использования

### Пример 1: Обычный пользователь
```
Запрос: { "carId": 1, "distanceKm": 15.0 }
Автомобиль: коэффициент 1.2
Пользователь: disabled = false

Расчет: 15.0 * 4.0 * 1.2 * (1 - 0/100) = 72.0
```

### Пример 2: Пользователь с ограниченными возможностями
```
Запрос: { "carId": 2, "distanceKm": 20.0 }
Автомобиль: коэффициент 1.5
Пользователь: disabled = true

Расчет: 20.0 * 4.0 * 1.5 * (1 - 3/100) = 116.4
```

## Тестирование

### Валидные сценарии:
1. Авторизованный, верифицированный, не заблокированный пользователь
2. Существующий автомобиль
3. Корректное расстояние > 0

### Невалидные сценарии:
1. Отсутствие авторизации → 401/403
2. Заблокированный пользователь → 403
3. Неверифицированный пользователь → 403
4. Несуществующий автомобиль → 404
5. Некорректное расстояние → валидация на фронтенде
