# Руководство по тестированию логирования Order

## 1. Быстрая проверка логирования

### Тестовый файл
Откройте файл `test-logging.html` в браузере для быстрой проверки формата логирования.

### Реальное приложение
1. Запустите бэкенд: `./mvnw spring-boot:run`
2. Запустите фронтенд: `cd frontend && npm run dev`
3. Откройте приложение в браузере
4. Перейдите на страницу карты (`/map`)
5. Откройте консоль разработчика (F12 → Console)

## 2. Что тестировать

### Создание заказа
1. Выберите автомобиль на карте
2. Установите точку назначения (клик на карте)
3. Дождитесь расчета стоимости
4. Нажмите "Создать заказ"
5. Проверьте консоль - должны появиться данные для создания Order

### Завершение заказа (с активным заказом)
1. Создайте заказ (см. выше)
2. Установите новую точку назначения
3. Нажмите "Завершить поездку" в панели активного заказа
4. Проверьте консоль - должны появиться данные для завершения Order

### Завершение поездки (без активного заказа)
1. Выберите автомобиль в статусе IN_USE
2. Установите точку назначения
3. Нажмите "Закончить поездку" в overlay
4. Проверьте консоль - должны появиться данные для завершения поездки

## 4. Проверка исправления ошибок

### Ошибка 404 для /api/user/orders/active
- Бэкенд теперь возвращает 200 OK с `null` в теле, если активного заказа нет
- Фронтенд правильно обрабатывает этот случай

### Ошибки leaflet-routing-machine
- Добавлены проверки `map.hasLayer()` перед удалением маркеров и маршрутов
- Ошибки "Cannot read properties of null" больше не должны появляться

### Ошибки компиляции TypeScript
- Исправлены ошибки в RideCostCalculator.tsx
- Все опциональные поля теперь имеют значения по умолчанию

## 5. Дополнительные проверки

### Проверка компиляции
```
cd frontend && npm run build
./mvnw compile -DskipTests
```

Оба команды должны выполняться без ошибок.

### Проверка формата данных
Убедитесь, что все логируемые данные:
1. Имеют понятные названия
2. Содержат все необходимые параметры
3. Форматированы для удобного чтения
4. Включают временную метку

## 6. Устранение неполадок

### Если логирование не появляется
1. Проверьте, открыта ли консоль разработчика
2. Убедитесь, что нет ошибок JavaScript на странице
3. Проверьте, что функция вызывается (добавьте `console.log('Функция вызвана')` в начало функции)

### Если данные неполные
1. Проверьте, что все переменные инициализированы перед логированием
2. Убедитесь, что асинхронные операции завершены
3. Проверьте структуру данных в отладчике

### Если появляются ошибки
1. Проверьте консоль на наличие ошибок JavaScript
2. Убедитесь, что все импорты корректны
3. Проверьте типы данных TypeScript
